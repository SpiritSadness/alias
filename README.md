# Alias

Первый рабочий прототип словесной игры для своей компании. Откройте сайт на телефоне и передавайте его между командами. После первого открытия игра работает без интернета.

## Как играть

- **Классический режим:** выбранная тема или весь словарь, 60 секунд на ход, +1 за угаданное слово, −1 за пропуск или ошибку (обе ситуации отмечаются кнопкой «Пропустить −1»). После окончания времени последнее слово остаётся на экране, и его может перехватить другая команда. На некоторых этапах включается ход перехвата из пяти слов без таймера. После достижения цели все команды получают одинаковое число ходов.
- **Кастом:** по умолчанию каждой команде даётся две минуты на любое число слов. После ходов всех команд сравниваются результаты раунда; очки за слова затем сбрасываются. Партия длится выбранное число раундов (по умолчанию три), а победителем становится команда, выигравшая больше раундов; ничья в раунде не даёт победы никому. Если после всех раундов число побед одинаковое, можно сыграть дополнительный раунд с одним ходом каждой команды или закончить вничью. При повторной ничьей выбор предлагается снова; если свежих слов не хватит на полный раунд, остаётся завершить партию вничью. Когда время хода истекает, последнее слово остаётся на экране для ответа любой команды. Длительность, тема, сложность и штраф за пропуск настраиваются; есть также таймер на каждое слово и альтернативная игра до заданного числа очков. В каждой команде первый объясняющий выбирается случайно, затем участники объясняют по кругу всей своей команде.
- Показанное слово сразу записывается в историю и больше не выдаётся на этом устройстве, даже после пропуска, отмены очков или новой партии. Историю можно скачать в JSON и восстановить на другом устройстве.

В офлайн-наборе 10 000 карточек по 13 темам и трём уровням сложности. Словарная база OpenRussian прошла автоматический отбор начальных форм, объединение вариантов и выборочную тематическую проверку; это не 10 000 полностью вручную отредактированных карточек. Данные распространяются по CC BY-SA 4.0, подробности в dist/word-data-notice.txt. Когда свежие слова в выбранной теме закончатся, игра сообщит об этом и не начнёт повторять их.
Каждая карточка содержит одно слово. Первая команда выбирается случайно при старте партии, а в раундовом режиме право начинать затем переходит по кругу.

## Запуск локально

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте `http://127.0.0.1:4173/`. Данные партии и история слов хранятся в IndexedDB браузера.

## Границы первой версии

Это игра на одном устройстве. Одновременная синхронизация нескольких телефонов пока не реализована; для переноса истории есть экспорт и импорт. Слова из встроенного набора конечны, поэтому абсолютную бесконечную новизну без пополнения словаря гарантировать нельзя.

## Установка и удобство

На главной есть ненавязчивая подсказка установки. Android/Chrome использует системный диалог, если браузер его предоставляет; для iPhone показана инструкция Safari → Поделиться → На экран Домой. Подсказка скрывается при запуске установленного приложения. Готовность без интернета показывается только после проверки кэша всех файлов и полного словаря.

Справа сверху находятся тема и звук; настройки сохраняются на устройстве. Звуки синтезируются локально через Web Audio после первого касания, по умолчанию включены. Каждый ход начинается с отсчёта 3–2–1; время угадывания запускается после него.

## Подготовка словаря

Исходные 324 карточки сохранены в data/seed-words.json. scripts/build-word-bank.py читает nouns.csv из OpenRussian (commit 50e210c4803237779cb562bc1abcea529066031c); scripts/finalize-word-bank.py применяет лексическую разметку и явные редакторские поправки. Для подготовки нужны Python, pymorphy3, nltk и корпус WordNet. Модель или сервер для игры не нужны. Результат — dist/word-bank.js и открытый dist/word-bank.json; отчёт отбора находится в data/word-audit.json. При добавлении слов сохраняются стабильные family и алиасы старых форм, чтобы прежняя история продолжала исключать уже показанное.

Неоднозначные по теме слова вынесены в «Разное»; тематическая разметка консервативна. Кнопка первого старта после редактирования поля больше не теряется: при изменении настройки обновляются только значения сводки, а кнопки сохраняются в DOM.

В итогах хода показаны изменения счёта всех команд и отдельное начисление последнего слова. Последнее слово, угаданное своей командой, входит в число угаданных; перехват соперником явно указан отдельно. История последних слов сохраняется в результатах раундов и партии, включая дополнительные раунды.
