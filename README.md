# Alias

Первый рабочий прототип словесной игры для своей компании. Откройте сайт на телефоне и передавайте его между командами. После первого открытия игра работает без интернета.

## Как играть

- **Классический режим:** 60 секунд на ход, +1 за угаданное слово, −1 за пропуск или ошибку (обе ситуации отмечаются кнопкой «Пропустить −1»). После окончания времени последнее слово остаётся на экране, и его может перехватить другая команда. На некоторых этапах включается ход перехвата из пяти слов без таймера. После достижения цели все команды получают одинаковое число ходов.
- **Кастом:** по умолчанию каждой команде даётся две минуты на любое число слов. После ходов всех команд сравниваются результаты раунда; очки за слова затем сбрасываются. Партия длится выбранное число раундов (по умолчанию три), а победителем становится команда, выигравшая больше раундов; ничья в раунде не даёт победы никому. Если после всех раундов число побед одинаковое, можно сыграть дополнительный раунд с одним ходом каждой команды или закончить вничью. При повторной ничьей выбор предлагается снова; если свежих слов не хватит на полный раунд, остаётся завершить партию вничью. Когда время хода истекает, последнее слово остаётся на экране для ответа любой команды. Длительность, тема, сложность и штраф за пропуск настраиваются; есть также таймер на каждое слово и альтернативная игра до заданного числа очков. В каждой команде первый объясняющий выбирается случайно, затем участники объясняют по кругу всей своей команде.
- Показанное слово сразу записывается в историю и больше не выдаётся на этом устройстве, даже после пропуска, отмены очков или новой партии. Историю можно скачать в JSON и восстановить на другом устройстве.

Всего в первом наборе 324 слова, сгруппированных по шести темам и трём уровням сложности. Когда свежие слова в выбранной теме закончатся, игра сообщит об этом и не начнёт повторять их.
Каждая карточка содержит одно слово. Первая команда выбирается случайно при старте партии, а в раундовом режиме право начинать затем переходит по кругу.

## Запуск локально

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте `http://127.0.0.1:4173/`. Данные партии и история слов хранятся в IndexedDB браузера.

## Границы первой версии

Это игра на одном устройстве. Одновременная синхронизация нескольких телефонов пока не реализована; для переноса истории есть экспорт и импорт. Слова из встроенного набора конечны, поэтому абсолютную бесконечную новизну без пополнения словаря гарантировать нельзя.
